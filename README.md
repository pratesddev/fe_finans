# Finans

**Landing page responsiva para apresentar uma ferramenta de organização financeira pessoal.**

## 📖 Sobre

O Finans é uma página institucional criada para apresentar uma solução de controle financeiro pessoal. O projeto demonstra como organizar informações sobre despesas, economia de tempo, categorias de gastos, alertas financeiros e suporte ao usuário em uma interface clara e responsiva.

A página foi desenvolvida com HTML, CSS e Bootstrap 5, utilizando componentes do framework e imagens PNG para construir uma experiência visual inspirada em uma landing page financeira.

---

## ✨ Funcionalidades

- [x] Barra de navegação responsiva com menu hamburguer
- [x] Área principal com formulário de cadastro por e-mail
- [x] Imagens ilustrativas e identidade visual em amarelo
- [x] Seções informativas sobre gastos e economia de juros
- [x] Três destaques: facilidade, economia de tempo e suporte
- [x] Rodapé com navegação e redes sociais

## 🚀 Começando

### Pré-requisitos

- Navegador web moderno
- Servidor HTTP local opcional

### Clonando o projeto

```bash
git clone https://github.com/pratesddev/fe_finans.git
cd fe_finans
```

### Executando

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como Live Server.

Também é possível iniciar um servidor HTTP local:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

---

## 💻 Uso

Navegue pelas seções da página pela barra superior ou pelo rodapé. Em telas menores, o menu é recolhido em um botão hamburguer.

O formulário de e-mail é uma representação visual da interface e ainda não realiza envio de dados.
